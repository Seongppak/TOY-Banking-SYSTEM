# TOY-Banking-SYSTEM

C 콘솔 뱅킹 프로그램입니다. 기존 업무 함수와 작업 내역 조회 흐름을 유지하면서
TXT 파일 기반 계좌 관리 및 신규 사용자 등록을 지원합니다.

## Visual Studio 빌드 및 실행

- 기존 솔루션 또는 `니마이 완성을 위한 프로젝트/니마이 완성을 위한 프로젝트.vcxproj`를 엽니다.
- 프로젝트의 기존 도구 집합은 v145이며 Windows SDK와 C++ 데스크톱 개발 도구가 필요합니다.
- Debug/Release, x64/Win32 구성을 사용할 수 있습니다.
- 디버거 실행 시 작업 폴더는 프로젝트 폴더입니다. EXE를 직접 실행할 때도
  `customer_info.txt`가 있는 폴더를 작업 폴더로 사용하십시오.
- 최초 빌드 시 출력 폴더에 TXT를 복사합니다. 이미 있는 출력 폴더의 데이터는
  재빌드 시 덮어쓰지 않습니다. 디버거와 출력 폴더 직접 실행은 각각의 TXT를 사용합니다.

## 계좌 파일과 입력

`customer_info.txt`와 C 소스 및 헤더는 **CP949**로 저장합니다.
MSVC는 `/source-charset:.949 /execution-charset:.949`로 컴파일하고,
Windows 콘솔 입력과 출력도 코드 페이지 949로 설정합니다.

각 줄의 형식은 `계좌번호 비밀번호 이름 잔액`입니다.
계좌번호는 양수인 long long, 비밀번호는 0~32767인 short, 잔액은 0 이상인
long long입니다. 이름은 공백 없이 CP949 기준 최대 19바이트입니다
(한글 음절은 2바이트이므로 최대 9글자).
최대 계좌는 100개이며, 잘못된 줄·중복 계좌·범위 초과가 있으면 파일 전체를
오류로 처리하고 기존 파일을 덮어쓰지 않습니다. 빈 파일에서는 첫 사용자를
등록할 수 있습니다. 파일이 없으면 오류로 종료합니다.

시작 메뉴에서 로그인, 신규 등록, 종료를 선택합니다. 중복 계좌 등록은
비밀번호를 추가로 묻지 않고 즉시 취소하여 시작 메뉴로 돌아갑니다.
신규 계좌 잔액은 0원입니다. 등록 및 입금·출금·이체 후 전체 계좌를
임시 파일에 기록하고 Windows의 파일 교체 기능으로 반영합니다.
저장 실패 시 등록/거래를 취소하며, 정상 종료 및 입력 종료 시에도 저장합니다.

## 기존 기능의 한계

- 이체는 기존 구현대로 송금 계좌에서 차감만 합니다. 수취 계좌 선택과
  수취 계좌 입금이 구현되어 있지 않습니다. 이번 변경에서는 유지했습니다.
- 작업 내역은 기존 struct log 배열에 최대 20개를 메모리로 저장합니다.
  재실행 후 거래 내역을 복원하는 기능은 기존에도 없으며 이번에도 추가하지 않았습니다.
- 작업 후 “네”를 선택하면 이름 확인과 내역 조회를 거쳐 시작 메뉴로 돌아갑니다.
  “아니오”는 바로 시작 메뉴로 돌아갑니다. 다른 계좌 로그인 시 작업 내역은 초기화됩니다.
  작업 메뉴의 “메인메뉴”도 시작 메뉴로 돌아가며, 시작 메뉴의 3번으로 종료합니다.
- 임시 파일 방식은 단일 프로그램 실행을 전제로 합니다. 여러 인스턴스의 동시 수정은 지원하지 않습니다.
